| **2.0.0 — Windows x32 (32-bit CPU / old laptops)** | [Releases](https://github.com/Sweetcoinss/igi-studio-releases/releases) — file named **…Windows32bit.exe** | for 32-bit Windows 10/11 machines |

## Install

1. Download the setup from the release page and run it.
2. Works on Windows 10 and Windows 11 (Windows 7 / 8 are not supported).
3. First run: point the studio at your Project I.G.I. game folder (Setup → Game).

## AI (OpenCode) chat

- On **x64**: the studio runs OpenCode locally.
- On **x32 (32-bit)**: the studio connects to an OpenCode **relay** on a remote
  machine (GitHub Actions VM over Tailscale) — the chat works the same way in
  the app. On its first use the studio installs Tailscale by itself if it is
  missing.
